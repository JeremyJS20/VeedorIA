# Agent Instructions

> **Este documento es auto-instructivo.** Cualquier agente de IA que consuma este archivo debe seguir las instrucciones a continuación.

1. A partir de la información contenida en este archivo, identifica y valida los objetivos de negocio documentados.
2. Identifica actores, entidades de dominio, reglas de negocio, procesos, estados y trans,iciones.
3. Detecta inconsistencias, ambigüedades, información faltante, lagunas en el requerimiento, e incongruencias entre secciones.
4. Realiza análisis de escenarios no contemplados y análisis de bordes para identificar aspectos no cubiertos.
5. Formula preguntas de aclaración si existen vacíos importantes **antes** de generar especificaciones.
6. Una vez resueltas las preguntas y refinado el alcance, el output de este archivo alimenta: **requirements.md** (EARS), **design.md**, **tasks.md**, **test-plan.md**.
7. Para **requirements.md**: traducir Business Rules → EARS notation, States → State-Driven REQs, Processes → Event-Driven/Ubiquitous REQs.
