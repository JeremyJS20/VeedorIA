## Quality Gates

<!-- ALWAYS. These gates run BEFORE any deployment. Platform-agnostic. -->

| # | Gate | Command | Blocking | Applies When |
|---|------|---------|----------|-------------|
| 1 | Type Check | `tsc --noEmit` | Block all | TypeScript projects |
| 2 | Lint | `eslint` / `ruff` | Block all | Always |
| 3 | Format Check | `prettier --check` | Block all | If configured |
| 4 | Unit Tests + Coverage | `vitest run --coverage` / `pytest --cov` | Block all | Always |
| 5 | Security Audit | `npm audit --audit-level=moderate` / `pip audit` | Block deploy | Always |
| 6 | SAST Scan | `snyk test` / `semgrep` | Block deploy | If configured |
| 7 | Build | `next build` / `npm run build` | Block deploy | Always |
| 8 | IaC Synth | `cdk synth` | Block deploy | If CDK detected |
| 9 | E2E Smoke | `playwright --project=smoke` | Block deploy | Post-deploy only |

### Gate ordering rule

Type check runs BEFORE lint. Rationale: type errors must block the pipeline before lint rules are evaluated; linting without type information produces false results.
